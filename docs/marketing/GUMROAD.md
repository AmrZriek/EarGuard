## Description

### A volume limit for unexpected Windows changes

Set a Windows volume limit for each listening device. EarGuard turns it down after unexpected changes.

EarGuard is free, portable, and open source for Windows 10 and 11.

### Set a limit that fits your setup

- Choose a hard volume ceiling for each playback device.
- Set a lower plug-in limit for new and reconnected devices.
- Start with Windows and leave EarGuard in the tray.
- Use one portable executable, with no installer or external dependencies.

### What it can and cannot do

EarGuard reacts to changes in Windows output volume and only turns it down. Enforcement is reactive, so a brief spike may get through before it responds. Some devices or drivers can block it entirely. A Windows volume percentage is not a sound-pressure measurement. EarGuard is an extra precaution, not a hearing-safety guarantee. Keep your listening level low.
